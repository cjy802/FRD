# FuXi 本地点预报订正应用

这个项目采用“两层模型”方案：

1. **FuXi-2.1 保持冻结**，负责生成全球基础天气预报。
2. **小型订正模型单独训练**，学习 FuXi 在目标地点的系统偏差，并输出更适合本地低空应用的结果。

本项目不会修改、微调或覆盖 `D:\低空经济\fuxi-2.1` 中的任何文件。

## 当前状态

- FuXi-2.1 模型目录：`D:\低空经济\fuxi-2.1`
- 本地观测数据：北纬 31.5°、东经 119.5° 的 ERA5 单点逐小时数据
- 观测时间：2025-01-01 00:00 至 2026-09-10 23:00
- 当前阶段：**先完成实施规划，尚未开始训练**

完整实施步骤见 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)。

## 核心数据流

```text
全球初始气象场（两个时刻、85通道）
               ↓
       FuXi-2.1 冻结推理
               ↓
    全球未来6小时至10天预报
               ↓
 抽取 31.5°N, 119.5°E 点位
               ↓
 与同一有效时间的 ERA5 观测对齐
               ↓
      训练小型本地订正模型
               ↓
       输出订正后的本地预报
```

## 重要限制

FuXi 自带的 `input.nc` 是 2024-09-29 的示例输入，而现有单点观测从 2025-01-01 开始，时间并不重合。因此：

- 可以先用示例输入验证 FuXi 是否能运行；
- 不能拿这次示例预报直接训练订正模型；
- 必须先生成或取得 2025-01-01 之后的历史 FuXi 预报，才能与现有观测组成训练样本。

在历史预报和观测尚未对齐之前，程序不得宣称已经完成订正模型训练。

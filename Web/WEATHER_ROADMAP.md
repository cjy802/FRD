按顺序实施，每项完成后更新记录、运行对应验证并创建本地 Git 提交。
现有自动取数、FuXi GPU 推理和全量订正模型继续使用。

- [x] 1. 区域天气与坐标匹配：保留江苏区域原生天气网格，支持真实航线位置查询和空间覆盖检查，修改点位时查询已有网格。
- [x] 2. 任务时间匹配：加入北京时间出发时刻，保留初始场和多时次预报，按沿线累计距离计算 ETA；区分瞬时变量与累计降水。
- [x] 3. 飞行高度匹配：自动补取 GFS 近地高度风、阵风和能见度；标明 AGL 高度及直接值/插值，拒绝无数据的外推。
- [x] 4. 沿线气象初筛：逐段计算高度风、顺逆风/侧风、降水和能见度提示，输出触发位置、原因和覆盖状态。
- [x] 5. 动态决策状态：替换写死的“数据不足”；分别显示预测、覆盖、初筛和剩余空域/障碍/机型核验状态。
- [x] 6. 飞行窗口比较：在资料覆盖的未来时次比较候选出发时间，输出排序依据和数据时间分辨率。
- [x] 7. 天气约束路线比较：用已覆盖的区域天气检查候选道路路线；没有可分辨差异时保留原路线，不强行宣称天气绕行有效。
- [x] 8. 联调与交付：测试异常/过期/范围外数据、真实 GPU 与公开数据、页面联动和不同屏幕，并完善启动说明。

## 约束

- 当前全量订正模型只在 31.5°N、119.5°E 的地面变量上训练；其他坐标和高度先使用有来源记录的原始区域预报。
- 原生天气网格约 0.25°；空间插值不能被描述为街道级预测。
- FuXi 原生预报时次相隔 6 小时；时间插值是估计，累计降水只能用于相应区间。
- 机型限制尚未配置时，只提供演示气象初筛，不给出“允许放飞”结论。
- 保留道路、空域和障碍物核验的独立状态；气象初筛通过不表示所有飞行条件通过。

验证：区域网格测试及前端生产构建通过。2026-10-08 真实 NOAA 起报 + GPU 推理 + 8011 接口已验证校园位置、训练点订正及空间范围外拒绝。

第 2 项已实现：同一次预测保留起报及未来 6/12/18/24h；新增沿线时间匹配接口和页面、北京时间出发输入、逐点 ETA、时次估计说明、六小时雨量区间及覆盖不足提示。修改时间/速度复用已有区域天气，不重新推理。
验证：后端 42 个测试、取数/推理 10 个测试、前端生产构建通过。真实校园路线 11/11 个采样点匹配成功；未来 24 小时范围外返回 `incomplete`。浏览器已验证实际校园天气、不同沿线 ETA、速度减半时航时翻倍、时间范围外提示及起点变化时旧路线不再用于天气匹配；修改参数后天气生成时刻不变。

第 3 项已实现：自动查询 NOMADS 江苏原生区域数据（失败时回退 NOAA S3 所选字段），包括 10/20/30/40/50/80/100 米 AGL 风及地面阵风、能见度，覆盖起报至未来 24 小时。直接高度层与高度/时间插值分别标识，超出 10–100 米拒绝外推。辅助资料失败保留真实 FuXi 地面预报，但高度覆盖明确为不足。
验证：实际 NOAA 五时次均通过区域筛选下载、16 通道 GRIB 解码；后端 47 个测试、取数/推理 13 个测试及前端构建通过。

第 4 项已实现：按道路段方向投影高度风，分别计算顺风/逆风/侧风；结合六小时降水、地面阵风/能见度输出逐点和逐段提示、最明显触发位置及原因。可选自定义阈值；默认演示规则，缺测不按零风评分，参考分不是事故概率，任何等级都不输出放飞许可。
验证：后端 52 个测试与前端生产构建通过，包含方向投影、阈值边界、零能见度、自定义阈值和高度缺测。

第 5 项已实现：决策文案随等待预测、请求失败、空间/时间/高度缺测及不同初筛等级变化；分项显示机型、空域、障碍物和未覆盖天气因素。自定义阈值仍标为未核验；地图按沿线初筛等级着色，并标明原生分辨率与不提供许可。修改起终点使旧路线失效。
验证：后端 54 个测试及前端构建通过；四类气象结果和自定义阈值均不能生成放飞许可。

第 6 项已实现：比较当前出发时间及未来原生时次，完整路线到达超出资料范围的候选被排除；先完整覆盖，再按初筛等级、参考分、出发时间排序。页面可显式选用候选并重新初筛，复用同一预测；不称为连续可飞行窗口，缺高度资料不产生有完整覆盖的推荐时次。
验证：后端 59 个测试及前端构建通过，覆盖排序、任务越界、过去时刻、辅助缺测和未知任务。

第 7 项已实现：本地在同一道路/建筑/端点接入约束下用重叠惩罚生成适度长度的备选；在线查询 OSRM 真实备选，不回退成本地或直线。天气比较要求完整覆盖、不同原生网格、显著变量差异、参考分改善及绕行长度约束；否则明确保留道路基线。页面支持显式采用道路参考线并重新初筛，不自动批准飞行、不保证全局最优。
验证：后端 63 个测试及前端构建通过；环形真实拓扑测试得到不同备选且几何距离未被惩罚权重污染。当前默认校园在这些约束下只得到基线路线，程序如实报告没有适度长度的备选。

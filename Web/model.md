# 气象驱动的低空水患巡查系统（构思稿）

更新日期：2026-10-14

## 1. 项目定位

面向城市排水和河湖防汛巡查，把公开气象、水情信息与无人机可见光（RGB）、热红外影像结合，回答两个现场问题：

1. **地面哪里疑似有积水？** 区分干燥路面、仅潮湿路面和有可见水面的积水区域，生成带位置、时间和原图的待核查记录。
2. **河湖沿岸哪里出现值得复核的变化？** 比较同一岸段不同时刻的水陆边界，寻找疑似漫溢、桥涵附近阻水物；对有堤防的岸段，尝试寻找背水坡疑似渗漏或管涌的表面迹象。

气象预报与官方预警用于确定**巡查区域和时段**，影像用于核查**现场可见变化**。系统输出“疑似异常及依据”，由巡查人员复核；它不提供无人机放飞许可，也不代替水文洪水预报或堤防工程鉴定。

## 2. 真实需求与本项目切口

- [江苏省水利厅《2026 年省水利科技项目申报指南》](https://jswater.jiangsu.gov.cn/art/2026/2/5/art_42984_11726109.html)第 50 项提出用无人机光学与红外热成像识别堤防低温差渗流、建立图像库和判别方法；第 53 项提出城市积水应急监测。这是公开的科研需求，**不是本项目已获得的订单**。
- [常州市水利局无人机巡查河湖项目成交公告](https://zfcg.changzhou.gov.cn/html/ns/dlcg_cjgg/443201576148464.html)显示，两包 2025 年度巡查服务分别成交 145 万元、153 万元。这证明本地有付费巡查业务，不能把合同金额当作“气象＋双影像识别”功能的收入。
- [河海大学的无人机红外—可见光堤坝巡查研究](https://jour.hhu.edu.cn/hhdxxbzr/article/abstract/20230320?st=aipub)做过实际工程巡测，支持双影像用于寻找堤坡渗漏表面迹象；复杂地面、温度变化和成像设备会影响结果。

因此，比赛原型宜聚焦**强降雨后的“城市积水＋重点河湖岸段”低空核查**。相比泛化的天气展示，交付物是可检查的异常位置、影像证据和复核清单。

## 3. 两个应用场景

### 3.1 城市地面积水

**输入**：区域降雨预报或官方预警、待巡查地点、无人机 RGB 照片；若设备可用，补充同地点二维热图。

**检测**：

- RGB 识别水面边界、纹理、倒影及镜面反光，重点区分“只有水膜的湿路面”和“存在一定范围水面的积水”。
- 热像仅在水面与周围地物存在可辨温差时提供辅助证据。刚停雨、整片地面潮湿或积水与路面达到热平衡时，热像可能无明显区分力；水面反射也会造成假温度。
- 对同一地点的前后影像做位置配准，记录新出现或扩大的疑似积水范围。

**输出**：疑似积水区域、RGB／热图原始证据、识别依据、需要人工确认的状态。仅凭这些影像不能给出可靠的积水深度或排水故障原因。

这里讨论的是**光反射或偏振特征**，不是把“光折射”当成第三台传感器。普通 RGB 图像已包含反光和倒影；若要利用偏振差异，需要不同偏振方向的影像或偏振相机。薄水膜也会反光，因此反光不能单独证明存在水坑。[可见光反射识别路面积水的研究](https://openaccess.thecvf.com/content_ECCV_2018/papers/Xiaofeng_Han_Single_Image_Water_ECCV_2018_paper.pdf)

### 3.2 河湖防汛巡查

**河道与湖岸的共通任务：水线和受淹范围变化。** 在固定岸段、固定拍摄点或经过几何配准的重复影像上提取水陆边界，比较河水、湖水是否新近覆盖步道、低洼岸段或设施。河道另检查桥涵、闸口附近可见的漂浮物聚集和疑似阻水点。

**有堤防岸段的专项任务：背水坡疑似渗漏。** 持续高水位可能形成堤内外水头差；在官方水情或现场水线提示需要加强巡查时，用热图定位局部温度异常，再用 RGB 查看湿痕、出水、浑浊或堤坡外观变化。温度异常只是线索，普通雨湿、阴影、植被和其他热源都可能造成误报；深埋且未在表面显现的险情不能由热像“透视”出来。[河海大学双影像巡查研究](https://jour.hhu.edu.cn/hhdxxbzr/article/abstract/20230320?st=aipub)

**输出**：水线变化图、疑似漫溢／阻水／渗漏点位、前后影像和人工复核清单。没有水尺或已知高程参照点时，只报告**相对水线或淹没范围变化**，不报告绝对水位、水深、流量或决口概率。[无人机视觉水位测量研究](https://www.mdpi.com/2073-4441/11/1/124)

## 4. 技术方案

```text
区域气象预报／官方预警 ─┐
                      ├─> 确定待巡查区域与时段
公开水情／现场水线 ───┘               │
                                      ▼
                         无人机 RGB 与二维热图采集
                                      │
                          时间、位置和图像配准
                                      │
                    RGB 候选识别 ＋ 热像辅助判别
                                      │
                       疑似异常图层与影像证据
                                      │
                           人工核查、处置、复拍
```

双影像融合的关键是**同一场景、接近的拍摄时间、可对齐的视场**。先分别建立 RGB 单独识别和热像单独识别的基线，再测试融合是否减少误报、漏报。热像无有效温差时，不应因为“热像没看到”而自动否定 RGB 发现的疑点。

相关论文说明技术路线可行，但结果不能直接套用到雨后城市道路：[GAM4water（MethodsX，2024）](https://www.sciencedirect.com/science/article/pii/S2215016124004060)在无人机河段数据上比较过 RGB 与 RGB＋热红外水域识别；[RGB＋长波热红外洪水监测研究（Remote Sensing，2024）](https://www.mdpi.com/2072-4292/16/13/2358)使用固定河岸相机分割水域。[卡内基梅隆大学的路面积水实验](https://mrsdprojects.ri.cmu.edu/2020teamb/implementation/perception-subsystem/)则记录了积水与湿路面温度接近、热像难以区分的反例。

## 5. 数据与设备边界

- **已有项目能力**：本仓库已接入 NOAA GFS → FuXi 区域预报、地图、道路参考路线和 DJI KMZ 航点草稿，见 [README.md](README.md) 与 [WEATHER_ROADMAP.md](WEATHER_ROADMAP.md)。图像识别、河道／桥涵数据索引、任务记录与防汛图层仍属于拟新增功能。
- **公开信息**：[江苏省水利厅每日水情](https://jswater.jiangsu.gov.cn/col/col55237/index.html)和官方预警网页可作有日期、有出处的案例输入；网页信息不能冒充稳定的实时 API，也不能把代表站水位外推为每个岸段水位。
- **气象尺度**：现有 FuXi 原生网格约 0.25°、时次相隔 6 小时，只能提供区域趋势背景，不能判断某个水坑、桥涵或堤段的实时状态。
- **热成像设备**：须核实独立设备是否输出二维热图、原始数据及拍摄时间。单点红外测温值不能生成积水轮廓；若无法稳定装载到无人机，可先做地面双影像实验。真正的机载融合还要解决挂载、供电、时间同步和视角配准。
- **地理数据**：项目原始江苏 OSM 文件含道路与水系等标签，但当前道路 SQLite 索引主要保存道路和建筑。提取河道、跨水道路等候选巡查点需要新增索引和人工核实；地图标注不等于工程资产台账。

## 6. 可执行的比赛验证

### 第一阶段：积水受控实验

在允许测试的同种地面材料上准备三类区域：**干燥、潮湿但无站立水、浅积水**。用常温水形成雨后场景，分别在刚洒水、地面部分干燥和不同光照时拍摄；RGB 至少包含俯视与斜视角度，并记录热图。单独标明这是受控模拟，不把它称作真实暴雨现场。

人工标出积水真值后，分别比较 RGB、热像、RGB＋热像的识别结果。核心指标是积水召回率、精确率、IoU，以及“湿而无积水”被误报的比例。测试集应按不同地点或拍摄时段划分，避免把同一段视频的相邻帧同时放进训练和测试。

### 第二阶段：河湖水线实验

在允许拍摄的同一河段或湖岸，记录固定标志物与拍摄位置，采集平常时段和雨后影像。人工标注水陆边界、可见漂浮物与受淹设施，检验前后配准和变化检测。若只有平常水位样本，就验证方法及误报，不宣称已验证洪水场景。

### 第三阶段：堤防疑似渗漏实验

若热像设备适合，可用**独立土箱或假坡面**设置有水渗出、普通雨湿、阴影和植被遮挡等对照，比较 RGB、热像和融合方法。该实验只验证“表面异常能否被找到”，不能证明实际堤防险情识别率；真实岸段仅用于合法、非破坏性的影像采集与人工核查。

### 第四阶段：完整流程演示

选一份明确日期的官方降雨／水情案例，例如[江苏省水利厅 2026-08-15 水情](https://jswater.jiangsu.gov.cn/art/2026/8/15/art_54071_11816673.html)，展示“天气与水情触发巡查区域 → 影像识别 → 疑点地图 → 人工复核记录”。**历史案例与后来自拍影像必须分别标注日期**，不能拼成同一次汛情实测。

## 7. 建议实施顺序

1. 确认热成像设备型号、二维热图导出方式和能否与无人机 RGB 影像配准。
2. 先完成三类地表积水样本采集、人工标注和三组识别对照；据结果决定热像是否真正带来增益。
3. 完成一个固定河／湖岸段的重复拍摄与水线变化展示。
4. 只有在双影像数据质量和验证结果足够时，再加入堤防疑似渗漏模块。

**比赛表述**：以气象和水情信息安排低空巡查，以 RGB／热像寻找可见水患迹象，形成可追溯的人工核查清单。识别精度、热像增益和行业价值以本项目实测为准。
